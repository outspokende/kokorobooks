# Historical implementation note

This file records an earlier design for a Piper-based server with MP3 downloads.
It is superseded by the current Kokoro/MLX backend and iOS streaming client.
The old engine and interaction plan below is not a setup guide or a statement
of current behavior.

For the current architecture and supported setup, use the root [README](README.md)
and [SETUP](SETUP.md). Current server configuration uses `KBS_ENGINE=kokoro`
by default and offers Kokoro's five built-in voices.
